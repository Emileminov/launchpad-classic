# Launchpad Classic

Тот самый Launchpad из прежних версий macOS — для тех, кому не нравится новый экран «Приложения».

## Скачать

**[⬇ Скачать Launchpad Classic (dmg)](https://github.com/Emileminov/launchpad-classic/releases/latest/download/LaunchpadClassic.dmg)**

Откройте dmg и перетащите **Launchpad Classic** в «Программы». Приложение подписано Developer ID и нотаризовано Apple — открывается без предупреждений. Нужна macOS 14 или новее.

## Что умеет

- Сетка 7×5 со всеми приложениями Mac, листание свайпом двумя пальцами, стрелками и точками внизу
- Папки: перетащите одну иконку на другую; название папки можно менять
- Перетаскивание как на iPhone: иконка «приподнимается», остальные расступаются, у края экрана листается страница
- Поиск: просто начните печатать, Enter запускает первый результат
- Удаление приложений: зажмите иконку (или держите ⌥), на иконках появятся крестики. Можно убрать приложение из Launchpad (останется на Mac, находится через поиск, там же возвращается правой кнопкой) или переместить в Корзину
- Горячая клавиша **⌃⌥Space**
- Анимации открытия, запуска приложения и раскрытия папок

Раскладка запоминается между запусками: `~/Library/Application Support/LaunchpadClassic/layout.json`.

## Сборка из исходников

```bash
./scripts/build.sh      # соберёт и установит в ~/Applications (ad-hoc подпись)
./scripts/release.sh    # подпись Developer ID, нотаризация и dmg (нужен свой сертификат)
```

Без Xcode-проекта: Swift Package, SwiftUI + AppKit.
